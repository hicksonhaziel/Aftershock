# Solami access and evidence policy

As reported by the project owner on September 27, 2026, the Solami team will use its own API keys during judging and allows another trial request after the supplied seven-day trial expires. This is a human renewal process, not automatic renewal or a guarantee of uninterrupted access. Before a live demonstration, run the bounded RPC/stream checks; request renewed trial access if they fail due to expiry. Keep the portable captured corpus available for offline development in the meantime.

Issued account access has worked for read-only mainnet RPC, bounded Yellowstone transactions and requested-slot replay. Dedicated streaming x-token authentication is the selected path; the standard key also worked in the initial slot probe. Trial activation is based on the team's issued account, not inferred from public marketing descriptions. No paid plan, pay-as-you-go setting or billing change has been activated by this project. Account billing status/quotas are not independently certified by these connectivity checks.

Configure each developer/judge's own `SOLAMI_RPC_URL`, `SOLAMI_STREAM_URL` and `SOLAMI_STREAM_TOKEN` in local `.env` or the server environment. Never bake keys into captures, exports, browser bundles or the repository. Check credentials without printing them. Keep initial setup independent of credentials: offline contracts, replay conversion and database checks work without provider access.

Yellowstone is the first supported capture transport. Mirage is not required for the first implementation and is not claimed tested. We retain binary `SubscribeUpdate` messages before decoding, distinguish ping/control frames from transactions, and do not treat a slot jump as proof of loss. Each capture has one stream session; the reconnect experiment links two separate processes. `fromSlot` replay is labelled provider replay, not newly observed live-only data.

The predicate is successful, nonvote transactions mentioning any configured account, including resolved writable/readonly addresses. This is distinct from invoking a program or decoding a trade. Reference retrieval uses finalized block enumeration and full transaction data with version ceiling 1. Missing/null/failed/unsupported evidence remains incomplete. Both surfaces use Solami, so independent reconstruction does not mean independent provider trust.

Two bounded reconnect experiments reobserved all 25 known boundary transactions and later-slot data. Two full-filter reference intervals found every recorded transaction but also additional matches in partly recorded boundary blocks. These are bounded observations, not guarantees of gap-free recovery under arbitrary outages. Raw recordings, exact RPC responses and checksummed reports remain in ignored local `.aftershock/` storage.

For public framing examples, the test fixtures are explicitly synthetic. For example hexadecimal `32 00` represents an empty Yellowstone ping submessage in a `SubscribeUpdate`; it is a protocol illustration, not live chain evidence. Tests also build synthetic transaction frames. Authentic evidence is identified by capture IDs, parent hashes, intervals and observed outcomes in the Phase 0 report; do not relabel synthetic fixtures as live data.
